# Sprint 17 - Client Meeting Summary

- Date: July 14th, 2026

## Project Updates

- The client shared that migration to the university infrastructure is still delayed due to slow internal IT processes.
- The issue has been escalated to higher management, and the client will continue following up with the IT department.
- We discussed the upcoming handover to the next student team, who will continue development and integrate the platform into the university infrastructure.
- Our goal is to hand over a stable and fully functional system.

## Feature Priorities

### Projects Feature

- The client identified the **Projects** feature as the highest remaining priority.
- We already have an initial implementation in progress.
- The client requested an early demo to provide feedback before project completion.

### Follow Feature

- We discussed implementing a follow system for alumni.
- Since it depends on a notification system, client gave it a lower priority given the remaining project time.

### Event Views

- Event view counters were discussed as a lightweight feature that could encourage user engagement.
- Profile views were also considered lower priority and can be discarded if not applicable.

## Technical Discussion

### Migration Status

- Migration remains blocked by university infrastructure and communication delays.
- The client will continue coordinating with the responsible IT staff to help resolve the issue.

### Telegram Restrictions

- Telegram bot messages are currently not being delivered due to server restrictions.
- Existing mini-app links still work, but new links and bot messages are unreliable.
- We are investigating possible workarounds.

### Notifications

- Mobile app notifications were discussed as a more practical approach than Telegram notifications.
- In-app notifications were also suggested as a possible future improvement by using a notification panel inside the app to show the notifications for upcoming events, which can be implemented on both platforms simultaneously.

## Agreed Priorities

- Prioritize completing the **Projects** feature.
- Continue working toward completing the migration.
- Resolve Telegram bot issues if possible within the remaining project time.
- Provide the client with a preview of the Projects feature for feedback before the final handover.
